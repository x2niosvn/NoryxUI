TÙY BIẾN THỜI GIAN THỰC

Đổi Giao diện & Màu chủ đạo

Mọi thành phần đều dùng biến CSS --nx-*. Thử nhấn chọn chế độ Sáng/Tối (hiệu ứng lan tỏa hình tròn) hoặc đổi màu chủ đạo bên cạnh để xem toàn trang thay đổi ngay lập tức.

Chọn màu chủ đạo (--nx-blue)
:root {
  --nx-bg: #0c0c0f;
  --nx-panel-bg: #121217;
  --nx-card-bg: #1b1b24;
  --nx-blue: #3b82f6;
}

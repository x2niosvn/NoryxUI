TÀI LIỆU NORYXUI

Tất cả Thành phần & Tiện ích

Bộ thư viện giao diện đầy đủ với thiết kế không viền mềm mại, tương phản cao Chế độ Sáng/Tối và kho biểu tượng NoryxIcons tích hợp sẵn.

Cài đặt nhanh (Install)

Nhúng trực tiếp 3 tệp của NoryxUI vào thẻ <head> và cuối <body>.

HTML
<link rel="stylesheet" href="assets/fonts/fonts.css" />
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/x2niosvn/NoryxUI@main/dist/noryxui.min.css" />
<script src="https://cdn.jsdelivr.net/gh/x2niosvn/NoryxUI@main/dist/noryxui.min.js" defer></script>

Biến CSS & Chế độ màu

Tùy biến giao diện toàn cục qua các biến --nx-* và thuộc tính data-theme="dark|light".

CSS
:root, [data-theme="dark"] {
  --nx-bg: #0c0c0f;
  --nx-panel-bg: #121217;
  --nx-card-bg: #1b1b24;
  --nx-blue: #3b82f6;
}

Điều khiển Hộp thoại, Ngăn kéo, Thông báo nổi và Chế độ Sáng/Tối qua đối tượng toàn cục NoryxUI.

JS
NoryxUI.theme.toggle(event);
NoryxUI.modal.open("#myModal");
NoryxUI.offcanvas.open("#myDrawer");
NoryxUI.toast({ title: "Thông báo", message: "Thành công!", type: "success" });
